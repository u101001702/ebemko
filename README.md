# EBEMKO — 實證野外醫療包最佳化

Evidence-Based Expedition Medical Kit Optimizer

依「活動 × 執行者等級 × 重量上限」求解野外醫療包配置。
4 個活動（登山／雪山／攀岩／溯溪）、29 種傷病、115 個處置技術、153 件裝備，
證據來自 38 個文獻與政府統計來源、147 筆文獻發現。

- **工具**：<https://u101001702.github.io/ebemko/>（單一 HTML 檔，求解在瀏覽器內執行）

## 這是建議，不是處方

覆蓋率的定義是「帶齊執行該技術某一層所需的全部必需裝備」，**不代表現場一定做得到**
—— 環境條件、時間與人力都不在這個模型裡。

## 已知限制

- 台灣本土溯溪與攀岩文獻為零，資料引用自歐美研究
- 成本維度目前只有重量，不含體積、現場操作時間與人力需求
- 部分小耗材重量為參考值或估計值，待實秤
- 同一格位可互相替代的品項，求解時一律挑最輕的
- 求解為貪婪法（兩種計分都跑取高分），不保證是全域最佳解
