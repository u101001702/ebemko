# EBEMKO — 實證野外醫療包最佳化系統（離線原型）

Evidence-Based Expedition Medical Kit Optimizer

依「活動 × 執行者權限 × 重量上限」求解野外醫療包配置的原型。
四個活動（登山／雪山／攀岩／溯溪）、187 個臨床技術、125 件裝備，
證據來自 38 個文獻與政府統計來源。

## 這是建議，不是處方

覆蓋率的定義是「帶了執行該技術所需的全部必要裝備」，**不代表現場一定做得到**
—— 執行者權限、環境條件、時間與人力都不在這個模型裡。

使用前請詳閱頁面上方的說明條，特別是關於個人輕裝配置的限制。

## 已知限制

- 攀岩與溯溪的台灣本土文獻為零，資料引用自歐美研究
- 成本維度目前只有重量，不含體積、現場操作時間與人力需求
- 部分裝備重量為類型預估而非實秤
